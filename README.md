# 📚 Online Book Store

An Online Book Store web application developed using **Laravel**.  
This project was created as a **Final Semester Project** in collaboration as team.  
The system allows users to browse, search, and purchase books online through a modern and user-friendly interface.

## 🚀 Features

### User Features
- User registration and login
- Browse books by category
- Search books by title or author
- View detailed book information
- Shopping cart functionality
- Checkout process
- Order history
- Responsive design

### Admin Features
- Admin dashboard
- Manage books (Add, Edit, Delete)
- Manage categories
- Manage users
- Manage orders
- Upload book images

## Installation

1. Clone the repository
2. Run `composer install`
3. Run `npm install`
4. Copy `.env.example` to `.env` and configure
5. Run `php artisan key:generate`
6. Run `php artisan migrate`
7. Run `php artisan serve`

## Setup Tailwind
1. `npm install tailwindcss @tailwindcss/vite`
2. Start your build process : `npm run dev`
